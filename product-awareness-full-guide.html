商品認知度
冒頭アプローチ
学習ガイド

読者が「商品」「欲求」「問題」をどこまで知っているかを見て、FV・冒頭・広告文・CTAを同じ判断軸で改善できるように整理した資料。

対象: アクシス記事部 / 広告運用者 用途: 学習・レビュー・制作判断 版: ゼロから学ぶ用

この資料でできるようになること

記事LPや広告で成果を出すには、商材の魅力をただ並べるだけでは足りない。読者がその商材や自分の悩みをどこまで認識しているかによって、冒頭で言うべきことが変わる。

この資料では、読者の状態を5段階に分け、その状態に合う6つの冒頭アプローチへつなげる。読み終わった時に、「この流入なら、まず何から話すべきか」を判断できる状態を目指す。

1. 読者の距離感を判定

商品、解決策、問題をどこまで知っているかを見る。

2. 冒頭の入口を選ぶ

商品から入るか、問題から入るか、物語から入るかを決める。

3. 業務に反映

FV、記事導入、広告文、CTA、不安払拭の量を調整する。

1. 基本の考え方

商品認知度とは、見込み客が「自分の問題」「解決策」「商品」をどこまで認識しているかを見る考え方。セールスライティングでは、売り手が言いたいことではなく、読者がすでに認識していることから話し始める。

たとえば、すでに商品を知っていて欲しい人に、長い共感や問題提起をすると遠回りになる。逆に、商品も問題も自分ごとになっていない人に、いきなり料金や予約ボタンを見せても動かない。

重要

同じ商材でも、流入面によって読者の認知度は変わる。検索で商材名を調べている人、悩み検索の人、SNS広告で偶然見た人、リターゲティングの人を同じ前提で扱わない。

認知度が高い人への入口

商品名、違い、証拠、価格、保証、申込方法、限定性を早めに出す。読者はすでに比較・検討に近い。

認知度が低い人への入口

問題、違和感、生活シーン、感情、物語、意外な事実から入る。読者はまだ商品を聞く準備ができていない。

直接言える時と、遠回りが必要な時

商品認知度が高いほど、価格、条件、予約方法などをそのまま見せても伝わりやすい。商品認知度が低いほど、商品を知らない人、問題に気づいていない人、広告に疑い深い人が多いため、商品説明の前に「聞く理由」を作る必要がある。

直接言ってよい時

商品が分かりやすい、読者が既存客、オファーが強い、約束が受け入れられやすい、商品改良や保証で購入不安を減らせている時。

遠回りが必要な時

商品説明が必要、読者が広告に飽きている、商品や主張を信じていない、問題や解決策をまだ認識していない、ニュース性や意外性がある時。

冒頭を決めるルール

出発点は「見込み客がすでに認識していること」か「次に知りたいこと」。問題認識なら問題から、解決認識なら欲しい未来や解決可能性から、商品認識なら選ぶ理由から、購買認識なら条件や申込方法から始める。

2. 商品認知度の5段階ピラミッド

上に行くほど、読者は商品に近い。下に行くほど、読者数は広くなるが、商品を直接売り込んでも届きにくい。大量に売りたい時ほど、下の層に降りる必要がある。その分、入口は間接的になる。

5. 購買認識商品を知っていて欲しい。あとは買う条件だけ。
4. 商品認識商品は知っているが、自分に合うか・信じてよいか迷っている。
3. 解決認識欲しい結果はあるが、どの商品や手段で叶うか知らない。
2. 問題認識問題には気づいているが、解決策があるとは思えていない。
1. 認識なし商品も問題も自分ごとになっていない。価値観や物語から入る。
注意

この5段階は、人を完全に分類するためのものではない。記事や広告を作る前に「今回はどの状態の読者を狙うのか」を仮置きするための判断フレーム。

3. 5段階の詳しい解説

1. 認識なし

商品も、自分の問題も、まだ明確に認識していない状態。健康でいたい、若く見られたい、ちゃんと働きたい、損したくない、かっこよく見られたい、という漠然とした感情はあるかもしれない。しかし、具体的な悩みや商品にはつながっていない。

ここで商品名や料金を出しても、「自分に関係ない」と流される。必要なのは、日常の違和感、価値観、セルフイメージ、ストーリー、意外な事実で注意を取ること。

足の痺れなら

足の痺れに気づいていない。健康でいたい気持ちはあるが、整体や治療を検討する段階ではない。

2. 問題認識

自分に問題があることは分かっているが、それを解決できる方法があるとは思えていない状態。不安、心配、フラストレーション、絶望、怒りが強い。読者は「これって自分だけなのでは」「このまま続くのでは」と感じていることが多い。

この段階では、悩みを正確に言語化するだけでも読者は反応する。ポイントは、表面的な症状だけでなく、生活や感情への影響まで代弁すること。ただし問題を長く煽りすぎず、早めに希望を提示する。

足の痺れなら

最近足が痺れる。少し不安。でも病院に行くべきか、整体でよいのか、そもそも治るのか分からない。

3. 解決認識

欲しい結果や解決したい悩みは分かっているが、具体的な商品や手段は知らない状態。「治したい」「改善したい」「普通に戻りたい」「もっとよくなりたい」は分かっているが、どこに行けばいいか、何を選べばいいかは分からない。

ここでは、読者の欲しい未来や悩みを言語化し、その未来へ近づく方法として解決策を提示する。いきなり商品名や料金だけを出すのではなく、「この悩みはこういう仕組みで解決できる」と橋渡しする。

足の痺れなら

足の痺れを治したい。普通に歩きたい。健康な状態に戻りたい。ただ、整体、病院、ストレッチ、サプリのどれがよいかはまだ分からない。

4. 商品認識

商品や候補は知っているが、まだ欲しいとは言い切れない状態。読者は「本当に自分に合うのか」「効果があるのか」「失敗しないか」「他と何が違うのか」で止まっている。

この段階では、商品の存在を知らせるより、選ぶ理由を作る。証拠、比較、口コミ、実績、保証、FAQ、専門性、料金の透明性などで不安を減らす。

足の痺れなら

整体、病院、ストレッチ、サプリなどを知っている。ただし、自分には何が合うのか、どこへ行くべきか決めきれていない。

5. 購買認識

商品を知っていて、欲しいと思っている状態。あとは買う手段、予約方法、価格、特典、保証、期限などを知りたい。ここでは長い教育より、行動に必要な情報を分かりやすく出す。

読者はすでに商品に近い。だから、CTA、申込手順、予約枠、キャンペーン、返金保証、よくある不安への短い回答を前に出す。

足の痺れなら

A整体院が自分の足の痺れに合いそうだと知っている。空き枠、料金、予約方法、初回の流れを知りたい。

4. 6つの冒頭アプローチ

商品認知度が分かったら、次は冒頭アプローチを選ぶ。ここでいう冒頭アプローチとは、ヘッドライン、サブヘッド、オープニングを含む最初の入り口。記事LPでも、広告でも、動画でも、読者が続きを見るかどうかはこの入口で大きく決まる。

最初に決めること

名前を先に選ぶのではなく、読者が今知っているものを確認する。商品を知っているならオファーやプロミス。問題だけ知っているなら問題解決や秘密。何も自分ごと化していないなら宣言やストーリーで注意を取る。

プロミス型 商品認識〜購買認識 読者が強く望む結果を大胆に約束する。 証拠や根拠がないと怪しくなる。

冒頭アプローチの選び方

認識なしストーリー、予言・宣言、秘密で注意を取る。
問題認識問題解決で感情を代弁し、希望を出す。
解決認識欲しい未来と解決策をつなぐ。
商品認識プロミス、証拠、比較で確信を作る。
購買認識オファー、保証、申込導線で行動を促す。

6種類別の構成と作り方

ここからは、実際に書く時の順番。記事LPではこの通りに全文を書く必要はないが、FV、冒頭、広告文、CTA前の教育を作る時の材料出しに使える。

オファー型取引条件から動かす

すでに欲しい読者へ、価格・特典・限定枠・保証など、行動判断に必要な情報を最初に見せる。

  1. オファーの中で一番魅力的な条件を選ぶ。
  2. その条件が読者にとってどんな価値になるかをベネフィット化する。
  3. なぜその条件で出せるのか、納得できる理由を添える。
  4. 商品詳細、保証、申込手順へ進める。
例: いつも買っているおむつ、欲しかったパソコン、行きたい整体院のように、読者がすでに分かっているものは価格・保証・空き枠を先に見せる。

プロミス型欲しい結果を約束する

商品候補を知っているが決め手がない読者へ、独自の強みを読者の欲求に変換して「この結果が得られる」と示す。

  1. 競合にはない独自価値、強み、違いを見つける。
  2. その独自価値を、読者が欲しい結果の約束に変える。
  3. 約束が本当だと分かる証拠、理由、口コミ、データを集める。
  4. 約束、証拠、商品詳細、オファーの順に並べる。
例: 足の痺れなら「条件に合う人は1時間以内に軽くする」と約束し、その理由を説明する。カメラなら「手ブレしにくく運動会をきれいに残せる」と伝える。

問題解決型悩みを代弁して希望を出す

問題は自覚しているが、商品や解決策を知らない読者へ、「その悩みは解決できる」と橋渡しする。

  1. 読者が夜も考えてしまう不安、心配、生活上の支障を見つける。
  2. 読者の頭の中の言葉、恥ずかしさ、不安、諦めを言語化する。
  3. 商品でその問題が解決できる証拠や理由を集める。
  4. 問題の場面、共感、解決可能性、商品詳細、オファーの順に進める。
例: 足の痺れ、冷えで眠れない、朝の関節の重さなど、本人がすでに困っていることから入り、原因と解決可能性へつなぐ。

秘密型知らない理由で読み進めさせる

「その話は聞いたことがない」と思わせ、好奇心で読み進めてもらう。問題認識から購買認識まで広く使える。

  1. 秘密にできる特徴、原因、仕組み、分類、独自メソッドを探す。
  2. その秘密が読者にどんなベネフィットをもたらすか確認する。
  3. 秘密に名前をつけ、知らないこととして認識しやすくする。
  4. ヒントや事例を小出しにし、十分に価値を伝えてから商品へ接続する。
例: 足の痺れが長引く人が見落としがちな原因、冷え対策で見逃されがちなポイントなど、「知らなかった」を入口にする。

予言・宣言型大胆な主張で注意を止める

認識なし寄りの読者に、ニュース、未来予測、新常識、意外な事実で「続きを見たい」と思わせる。

  1. 資料や市場から、読者にとって驚きのある事実を探す。
  2. その事実を大胆な宣言や未来予測に変える。
  3. 宣言が本当だと分かる証拠、根拠、生活実感を示す。
  4. 宣言から導かれる行動と、商品を自然につなげる。
例: 「これからのパソコン選びはスペック表だけでは決められません」「関節の不調は年齢だけの問題とは限りません」のように、思い込みを止める。

ストーリー型疑似体験で自分ごと化する

物語で警戒心を下げ、感情移入させる。認識なしにも使えるが、内容次第ではどの認知度にも接続できる。

  1. 問題解決ストーリーか、商品開発ストーリーかを決める。
  2. 一番商品の魅力が伝わる出来事、人物、変化を選ぶ。
  3. 本人や開発者への確認など、詳細情報を集める。
  4. 悩み、葛藤、出会い、変化、現在の生活、商品詳細の順に整理する。
例: 足の痺れを我慢していた人の変化、冷えで眠れなかった人の習慣変更、食事に自然に誘える相手とそうでない相手の違いなど、追体験できる話から入る。
注意

秘密、宣言、ストーリーは強力だが、面白さだけで商品と関係が薄いと離脱を生む。どの型でも、最終的には商品が解決する問題、叶える欲求、行動する理由へ戻す。

5. 具体例で理解する

食事に誘う例

商品認知度は、人間関係に置き換えると分かりやすい。すでに仲が良い相手なら「今日食べに行かない？」で伝わる。相手はあなたを知っていて、誘いの意味も分かっている。

しかし、まったく知らない相手に同じ言い方をすると警戒される。まず話しかける理由、聞いてもいいと思える入口、安心材料が必要。広告も同じで、商品を知らない人には、商品説明の前に「聞く理由」を作る必要がある。

足の痺れ・冷え・睡眠・関節の例

読者の状態 認知度 冒頭の入り方 後半で必要なもの
足の痺れや冷えを、まだ大きな問題だと思っていない 認識なし 健康でいたい気持ち、歩く不安、眠れない日の違和感から入る。 問題に気づくための話、身近な生活場面。
「足が痺れる」「足先が冷えて眠れない」「朝だけ関節が重い」 問題認識 悩みの場面と、不安を言葉にする。 原因、同じ悩みの多さ、解決できる可能性。
「足の痺れを治したい」「睡眠を良くしたい」「関節を楽にしたい」 解決認識 欲しい未来と、解決方法の選択肢をつなぐ。 仕組み、理由、実績、どんな人に合うか。
整体、サプリ、ストレッチ、寝具など候補を知っている 商品認識 どれが自分に合うか、なぜそれを選ぶべきかを見せる。 比較、口コミ、保証、よくある疑問。
行きたい整体院、買いたい寝具、試したいサプリが決まっている 購買認識 価格、空き枠、買い方、保証、期限を見せる。 申込手順、最後の不安払拭。

広告運用での見方

広告運用者は、広告文と記事LPの認知度がズレていないかを見る。広告文が悩み訴求なのに、記事FVがいきなり商品名と価格だけだと、読者の心理がつながらない。逆に、リターゲティングで既に商品を知っている人に、長い問題提起から入ると遠回りになる。

運用者のチェック

広告文が「悩み」から入っているなら、記事FVも問題認識/解決認識に合わせる。広告文が「商品名・価格・キャンペーン」なら、記事FVは商品認識/購買認識に合わせる。

6. 記事部・運用者の使い方

記事部が使う場面

  • FVを作る前に、読者の認知度を仮置きする。
  • 共感を厚くするべきか、証拠を前に出すべきかを決める。
  • CTAを早く出してよいか、教育後に出すべきかを判断する。
  • 競合CRを参考にする時、見た目だけでなく想定認知度が同じか確認する。

広告運用者が使う場面

  • 広告文と記事FVの温度感が一致しているか確認する。
  • 配信面ごとに、悩み訴求、商品訴求、オファー訴求を分ける。
  • 同じ記事でも、どの認知度の流入に向いているかを判断する。
  • 数値が悪い時、広告文の問題か、記事入口の認知度ズレかを切り分ける。

レビュー会での使い方

レビュー会では、「FVが弱い」「共感が足りない」「オファーが見えない」と感覚で話す前に、まず読者の認知度を合わせる。問題認識向けの記事なら共感や問題の言語化が重要。商品認識向けの記事なら、証拠、比較、不安払拭、オファーが重要になる。

レビュー会で使う質問

この記事は、商品を知っている人に売る記事ですか？ それとも、悩みだけある人に商品を知ってもらう記事ですか？ この質問に答えられると、冒頭で何を直すべきかが見えやすくなる。

7. 制作チェックリスト

  • 流入面ごとに読者の認知度を仮置きしたか。
  • 読者が商品を知っている前提で書いてよいか確認したか。
  • 読者が解決策を知っている前提で書いてよいか確認したか。
  • 読者が自分の問題を言葉にできているか確認したか。
  • 見込み客がすでに認識していること、または次に知りたいことから冒頭を始めているか。
  • 認知度が低いのに、商品名・価格・予約導線を急いでいないか。
  • 認知度が高いのに、長い共感や基礎教育で遠回りしていないか。
  • 選んだ冒頭アプローチに必要な証拠や希望が入っているか。
  • オファーなら条件、プロミスなら独自の強みと証拠、問題解決なら悩みの場面、秘密なら名前付きの未知情報、宣言なら根拠、ストーリーなら取材材料を集めたか。
  • 広告文と記事FVの認知度がズレていないか。
  • CTA前に、読者が行動できない理由を潰しているか。
  • 迷った時、複数パターンとトレードオフを出したか。

8. すぐ見返す用
