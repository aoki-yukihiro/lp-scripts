商品認知度 早見ガイド
5段階と6つのリード戦略

記事LPや広告の冒頭で迷った時に、30秒で「誰に、何から話すか」を決めるための簡易版。詳しく学ぶ前に、まず現場で使う判断表として見る。

対象: アクシス記事部 / 広告運用者 用途: FV・リード・CTA・広告文の判断 版: すぐ見返す用
1分読者の認知度を仮置きする
5段階認識なしから購買認識まで
6リード入口の型を選ぶ
明日から記事・広告の冒頭に反映する

まずこれだけ覚える

商品認知度とは、読者が「自分の問題」「解決策」「商品」をどこまで知っているかを見る考え方。記事LPや広告では、売り手が言いたいことからではなく、読者がすでに認識していることから話し始める。

認知度が高い人

商品や解決策を知っている。遠回りせず、商品名、証拠、比較、オファー、申込導線を早めに見せる。

認知度が低い人

まだ自分ごと化していない。商品名より先に、悩み、違和感、感情、ストーリー、意外な事実から入る。

実務ルール: 同じ商材でも、商材名検索、悩み検索、SNS広告、リターゲティングでは認知度が変わる。流入面ごとに仮置きする。
リード選定の鉄則

見込み客がすでに認識していること、または「次に知りたいこと」から始める。商品を知らない人には商品名ではなく悩みや違和感、問題に気づいていない人には物語や意外な事実から入る。

ズレると起きること

問題認識の人に価格だけを見せても「何の商品？」で止まる。購買認識の人に長い共感を見せると「早く条件を見せて」で離れる。入口の早すぎ・遅すぎを防ぐのが商品認知度。

5段階の早見表

段階 読者の状態 冒頭で言うこと 急がないこと 足の痺れなら
認識なし 商品も問題も、まだ自分ごとではない。 日常の違和感、価値観、ストーリー、意外な事実。 商品名、料金、予約導線。 足の痺れに気づいていない。健康でいたい程度。
問題認識 問題には気づいているが、解決策があるとは思えていない。 悩みの具体化、生活の支障、不安や恐れの代弁。 いきなり商品紹介へ飛ぶこと。 最近足が痺れる。不安だが、どうすればよいか分からない。
解決認識 欲しい結果はあるが、どの商品・手段で叶うか知らない。 欲しい未来、解決可能性、解決策の提示。 商品名や料金だけを出すこと。 足の痺れを治したい。普通に歩ける状態になりたい。
商品認識 商品や候補は知っているが、自分に合うか迷っている。 選ぶ理由、証拠、比較、口コミ、保証、不安払拭。 商品名だけで売れる前提。 整体、病院、ストレッチ、サプリなど候補を知っている。
購買認識 商品を知っていて欲しい。あとは買うだけ。 価格、申込方法、予約枠、期限、特典、保証。 長い共感や基礎教育。 A整体院で改善できそう。予約方法と空き枠を知りたい。

見出し例で見る6つのリード戦略

表だけで決めにくい時は、まず「冒頭の見出しにしたらどうなるか」で考える。下の例は、美容医療のクマ取り・目元悩みに寄せた使い方。

オファー条件が良いから今動く入口
見出し例
  • 今月限定、クマ取りの無料相談枠を受付中
  • モニター枠残りわずか。目元悩みを特別価格で相談できます
  • 費用・ダウンタイム・適応を予約前にまとめて確認

使う場面: 商材名検索、リターゲティング、キャンペーン告知など、読者がすでに商品や院を知っている時。

作る時: 価格、特典、期限、枠数、相談条件、保証制度がある場合の不安払拭を先に見せる。

プロミス欲しい未来を最初に見せる入口
見出し例
  • 疲れて見える目元から、明るい第一印象へ
  • 鏡を見るたび気になるクマ悩みに、切らない選択肢も
  • メイクで隠す毎日から、すっぴんの目元に自信を

使う場面: 商品認識から購買認識。悩みも解決策も分かっていて、「結局どう変われるのか」を知りたい時。

作る時: 結果だけを強く言い切らず、症例、医師、口コミ、仕組みなどの証拠をすぐ近くに置く。

問題解決悩みを言語化して希望へつなぐ入口
見出し例
  • 「寝不足？」と聞かれる目元、実はクマの種類が原因かも
  • 写真の自分だけ老けて見える。そんな目元悩みの見直し方
  • コンシーラーで隠しきれないクマに悩む人へ

使う場面: 悩み検索、SNS広告、共感導入。読者は困っているが、まだ施術や商品に直結していない時。

作る時: 生活シーン、感情、困りごとを先に出し、次に原因と解決可能性へ進める。

秘密知らなかった原因で読み進めさせる入口
見出し例
  • クマが濃く見える本当の理由は、睡眠不足だけではありません
  • 目元の影を濃くする人が見落としがちな3つの原因
  • 同じクマでも、青クマ・茶クマ・黒クマで対策は変わります

使う場面: 問題認識から解決認識。悩みはあるが、なぜ起きるのか、何を選べばよいか分からない時。

作る時: 「知らないと損」だけで煽らず、分類、原因、仕組み、専門家視点で納得感を作る。

予言・宣言意外な主張で注意を止める入口
見出し例
  • これからの老け見え対策は、ファンデより目元ケアが重要です
  • 「疲れ顔」は年齢のせいだけではなく、目元の影で決まる
  • 美容医療は、隠す時代から原因に合わせて選ぶ時代へ

使う場面: SNS広告や広い潜在層。読者がまだ悩みを深く考えていないが、価値観のズレや新常識には反応する時。

作る時: 大きな主張の後に、なぜそう言えるのかをデータ、症例、生活実感、専門家の説明で支える。

ストーリー1人の体験で自分ごと化させる入口
見出し例
  • 同窓会の写真を見て、初めて目元の変化に気づいた話
  • マスクを外した瞬間、「疲れてる？」と言われた日のこと
  • 毎朝コンシーラーを重ねていた私が、相談を決めるまで

使う場面: 認識なしから問題認識。いきなり商品を出すと読まれにくい、広い潜在層向けの導入。

作る時: 出来事、感情、気づき、調べ始める理由、解決策との出会いの順で、自然に商品へ接続する。

5段階と6つのリード戦略

認識なしストーリー、予言・宣言、秘密。まず注意と自分ごと化。
問題認識問題解決、秘密、予言・宣言。不安を言語化して希望へ。
解決認識問題解決、秘密。欲しい未来と解決策をつなぐ。
商品認識プロミス、USP、証拠。なぜこの商品かを示す。
購買認識オファー、保証、限定性。行動に必要な情報を出す。
リード戦略 向く読者 入口の作り方 記事LPでの使い方
オファー 購買認識、最大意識 価格、保証、特典、期限、条件を最初に見せる。 リタゲ、既存顧客、商材名検索、キャンペーン訴求。
プロミス 商品認識、購買認識 読者が強く望む結果を大胆に約束し、証拠で支える。 「この商品で何が変わるか」をFVや導入で示す。
問題解決 問題認識、解決認識 悩み、心配、不安、生活の支障を言語化し、希望を出す。 悩み検索、SNSの潜在層向け記事、共感導入。
秘密 解決認識、問題認識、認識なし寄り 「知らない理由」「隠れた仕組み」「成功の裏側」で好奇心を作る。 原因説明、仕組み紹介、専門家/業界の知見。
予言・宣言 問題認識、認識なし寄り 大胆な主張、未来予測、意外な事実でパターンを止める。 市場変化、制度変更、今すぐ知るべき理由。
ストーリー 認識なし、広い潜在層 人の感情の動きで抵抗を下げ、商品や約束へ接続する。 体験談、開発秘話、悩みのある1人の物語。

6リードを作る時の最短手順

迷ったら、リード名から考えるより「何を材料にして、どの順番で見せるか」まで落とす。

リード 最初に集める材料 冒頭の並べ方 使う前の確認
オファー 価格、割引、特典、限定枠、保証、予約条件。 一番魅力的な条件 → その価値 → なぜ今その条件なのか → 商品詳細。 読者はすでに商品や解決策を知っているか。
プロミス USP、競合との違い、症例、実績、口コミ、理由。 欲しい結果の約束 → なぜ叶うかの証拠 → 商品詳細 → オファー。 約束を証明する根拠があるか。
問題解決 悩み、不安、夜に考えること、生活の支障、解決根拠。 問題が出る場面 → 感情の代弁 → 解決可能性 → 商品詳細。 読者がその問題を自覚しているか。
秘密 知られていない原因、仕組み、分類、独自技術、名前をつけられる要素。 秘密の存在 → ヒント → ベネフィット → 商品で詳しく知れる流れ。 秘密の正体が読者にとって得になるか。
予言・宣言 驚きの事実、市場変化、データ、新常識、今後起きる不利益/チャンス。 大胆な宣言 → 根拠 → 取るべき行動 → 商品との接続。 宣言が読者の生活や悩みに関係しているか。
ストーリー 悩みが変わった体験、開発背景、利用者の変化、印象的な出来事。 変化を暗示 → 悩み/葛藤 → 出会い/発見 → 結果 → 商品詳細。 面白いだけでなく、商品や約束へ自然につながるか。

流入面別にまず仮置きする

流入 多い認知度 冒頭の優先順位 運用/制作の見方
商材名検索 商品認識〜購買認識 比較、実績、症例、価格、保証、申込導線。 「知っているが迷っている」不安を潰す。
悩み検索 問題認識〜解決認識 悩みの言語化、解決可能性、原因、解決策。 悩みと商品を早くつなぎすぎない。
SNS広告 認識なし〜問題認識 違和感、生活シーン、感情、ストーリー、意外な事実。 商品名より先に「自分の話だ」と思わせる。
リターゲティング 商品認識〜購買認識 再提示、限定性、保証、予約枠、口コミ。 教育よりも背中を押す材料を前に出す。

美容医療記事でのざっくり使い分け

読者の言葉 認知度 FV/導入の方向 置くべき証拠
「なんか老けて見える」「疲れて見える」 問題認識 生活シーン、見た目の印象、感情の代弁。 原因、同じ悩みの多さ、解決可能性。
「クマをどうにかしたい」 解決認識 クマの種類、改善の選択肢、施術の位置づけ。 症例、仕組み、安全性。
「クマ取りが気になる」 商品認識 失敗不安、ダウンタイム、料金、院選び。 BA、口コミ、医師、保証、FAQ。
「この院で受けたいかも」 購買認識 予約枠、価格、キャンペーン、手順。 申込導線、限定性、最終不安払拭。

制作前チェックリスト

  • この読者は、商品名を知っているか。
  • この読者は、解決策があると知っているか。
  • この読者は、自分の問題を言葉にできているか。
  • 見込み客がすでに認識していること、または次に知りたいことから始めているか。
  • 流入面ごとに認知度を変えて考えたか。
  • 高認知度に長い共感を置きすぎていないか。
  • 低認知度にいきなり商品名や価格を出していないか。
  • 選んだリード戦略が、読者の認知度と合っているか。
  • オファー、プロミス、問題、秘密、宣言、ストーリーのうち、今回の入口に必要な材料を集めたか。
  • CTA前に、読者の不安や疑問が潰れているか。
迷った時: 1つに決めつけない。商品認識寄りと問題認識寄りなど、2パターンを出して、広告文・流入面・過去実績で判断する。
